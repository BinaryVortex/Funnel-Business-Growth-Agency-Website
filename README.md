# Funnel — Business Growth Agency Website

A clean, responsive landing page template for a marketing / funnel agency built with plain HTML, CSS and a small amount of JavaScript.

This repository contains a single-page website ideal for showcasing services, capturing leads, and presenting case studies for growth-focused agencies.

## Features

- Modern, responsive landing page layout
- Hero section with call-to-action
- Services, portfolio/case studies and contact sections
- Mobile-first CSS with reusable utility classes
- Small JavaScript for interactive UI elements

## Tech

- HTML
- CSS (primary)
- JavaScript (small interactive bits)

The repo language composition (approx): CSS 53%, HTML 45%, JavaScript 2%.

## Getting started (run locally)

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Funnel-Business-Growth-Agency-Website.git

2. Change into the project directory:

   cd Funnel-Business-Growth-Agency-Website

3. Open the site in your browser:

   - Double-click `index.html`, or
   - Serve it with a simple HTTP server (recommended for testing JS/CORS):

     Python 3:
     ```bash
     python -m http.server 8000
     # then open http://localhost:8000 in your browser
     ```

## Customization

- Edit `index.html` to change content and structure.
- Update styles in `style.css` for layout, colors, and typography.
- Modify `script.js` to change interactive behaviours (nav, form handling, etc.).
- Add images and assets in the repository (keep paths relative) and update the markup to reference them.
